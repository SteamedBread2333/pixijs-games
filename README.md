# 合成大西瓜

基于 **PixiJS** + **Matter.js** 的合成大西瓜网页小游戏。

在线体验：https://SteamedBread2333.github.io/pixijs-games/

## 玩法

- 移动鼠标/手指瞄准，点击投放水果
- 相同水果碰撞合成更高级水果，最终合成大西瓜
- 堆积超过红色警戒线即游戏结束

## 特色

- 道具：💣 炸弹移除水果、🫨 震动重排、✨ 进化升级
- 连击倍率最高 ×5，本地记录最高分
- 每累计 200 分获得随机道具

## 本地运行

```bash
npm install
npm run dev
```

## 部署

推送 `main` 分支后由 GitHub Actions 自动发布到 GitHub Pages。
